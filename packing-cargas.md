## Manual Packing <a id="manual-packing"></a>

*Manual E — Operations 2*

### Overview <a id="overview"></a>

The manual packing system allows you to pack outbound product into shipping “cartons” or containers that can hold or be linked to their “contents”, which is the product on the orders. You link shipping cartons to their contents by means of carton ID’s and label ID’s. Carton ID’s come from an external source such as a roll of preprinted labels. Label ID’s, on the other hand, are unique numbers generated by AccellosOne 3PL that print on a pick label. This label shows the product to be picked as well as the location.
When you pack a shipping carton, you attach the label ID’s of the product that you are shipping to the carton 
ID of the carton or container in which it is shipped. 
If you set up packing stations for manual packing, you can specify a specific printer for each order’s documents based on the packing station to which the order is sent.
The manual packing system is offered in maintenance mode only. No further development to this system is planned at this time.

### HOW LABEL ID’S ARE GENERATED <a id="how-label-id-s-are-generated"></a>

The number of labels printed and the number of label ID’s generated depend upon the quantity breakdown of the item and the number of units being shipped. For example, suppose your quantity breakdown for a given item is as follows:
1 each = 1 each
5 eaches = 1 case
20 cases = 1 pallet
AccellosOne 3PL will roll up the shipping quantity to the highest SKU and then print the required number of labels. For example, if your shipping quantity is 55 cases, AccellosOne 3PL will print two labels for two pallets and 15 labels for the remaining 15 cases. If your shipping quantity were 33 eaches, AccellosOne 3PL will print six labels for six cases and three labels for three eaches.
The number of label ID’s (that is, the contents) per carton ID (that is, the container) is user defined. You decide at the time of packing how many label ID’s you wish to attach to a single carton ID. You can create a carton ID for each box shipped or you can place a number of eaches in a box and assign that box a single carton ID.
NOTE A “carton” in AccellosOne 3PL is any product with a carton ID assigned to it. 
Carton ID’s can be assigned to any SKU code that is part of an item’s quantity breakdown. For example, if your quantity breakdown is pallet/case/each, your “carton” can be a pallet, case or each.

### Overview <a id="overview"></a>

The Quick Response system allows you to generate and print MH10 or UCC-128 shipping labels for outbound product. You can generate labels for both inventory items as well as non-inventory items such as shipping containers, pallets, cages and other equipment used to hold product.

 a nine-digit serial number (sequentially generated by Warehouse-Logic)
 a one-digit check digit the check digit the twodigit prefix the type of shipping container the sevendigit member number the nine-digit serial number
